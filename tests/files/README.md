# Bats Test Cases

This directory contains test definitions executed by Bats:

- **`common.bats`**: Verifies cross-platform configurations: validates that `managed.zshrc`, `managed.zshenv`, `init.lua`, `vimrc`, `tmux.conf`, `config.ghostty`, and `starship.toml` exist after apply, checks Zsh syntax and plugin order, validates pinned tools and repository tasks in `mise.toml`, file tasks in `mise-tasks/`, and Python CLI tools in `dot_config/mise/config.toml`, tests `run_once_setup-chezmoi-git-identity.sh.tmpl`, `run_zsh-setup.sh`, and `run_after_setup-ssh.sh`, validates shared `AGENTS.md`, harness symlinks/imports across tools (Claude, OpenCode, Pi, agy, Copilot), the Claude settings modify script, `statusline.sh` formatting, and `aws-sso-expiry.sh` parsing/caching and Starship prompt rendering.
- **`data.bats`**: Tests Go template rendering for dynamic files (`dot_config/git/private_config.tmpl` and `dot_config/homebrew/private_Brewfile.tmpl`) and template scripts (`run_onchange_after_brew-bundle.sh.tmpl`) across different variables (`machine_type` = personal vs work, custom emails) and manifest edits.
- **`macos.bats`**: Validates existence, executable permissions, and bash syntax parsing of macOS provisioning scripts (`run_once_after_macos.sh`, `run_once_before_install-homebrew.sh`, and `run_onchange_after_brew-bundle.sh.tmpl`), and verifies the Caps Lock to Control modifier mapping.
