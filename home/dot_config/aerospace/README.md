# AeroSpace Configuration (`dot_config/aerospace/`)

Houses configuration for [AeroSpace](https://github.com/nikitabobko/AeroSpace), an i3-like tiling window manager for macOS.

### Files

- **`private_aerospace.toml`**: Maps to `~/.config/aerospace/aerospace.toml`. Configures window tiling layouts, workspace bindings, app-specific assignment rules, and keyboard navigation shortcuts using the `alt` (Option) modifier.
