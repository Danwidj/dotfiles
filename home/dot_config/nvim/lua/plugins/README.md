# Neovim Plugins (`dot_config/nvim/lua/plugins/`)

Contains plugin specifications loaded by `lazy.nvim`.

### Files

- **`private_colorscheme.lua`**: Configures the primary colorscheme (Catppuccin).
- **`private_lsp-python.lua`**: Configures Python LSP, linters, and formatters (e.g. Pyright, Ruff).
- **`private_lsp-bash.lua`**: Configures Bash language server (`bashls`) and ShellCheck integration.
- **`private_oil.lua`**: Configures [oil.nvim](https://github.com/stevearc/oil.nvim) for file navigation and editing directories like buffers.
- **`private_snacks.lua`**: Configures [snacks.nvim](https://github.com/folke/snacks.nvim) utility modules.
- **`private_theme.lua`**: Theme styling adjustments and highlights.
- **`private_example.lua`**: Reference template for adding new plugin specifications.
