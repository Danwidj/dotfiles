# tmux Themes (`dot_config/tmux/private_themes/`)

Contains theme palettes for tmux.

### Files

- **`private_dark.tmux`**: Maps to `~/.config/tmux/themes/dark.tmux`. Applies the [Catppuccin Mocha](https://github.com/catppuccin/tmux) dark palette to the tmux status bar, active panes, and window tabs.
- **`private_light.tmux`**: Maps to `~/.config/tmux/themes/light.tmux`. Applies the [Catppuccin Latte](https://github.com/catppuccin/tmux) light palette.
