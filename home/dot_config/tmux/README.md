# tmux Configuration (`dot_config/tmux/`)

Houses configuration for [tmux](https://github.com/tmux/tmux), the terminal multiplexer.

### Files

- **`private_tmux.conf`**: Maps to `~/.config/tmux/tmux.conf`. Configures prefix key, pane splitting, mouse support, vim-style window navigation, true-color terminal support, and dynamically loads the Catppuccin theme from `themes/`.

### Subdirectories

- **`private_themes/`**: Contains modular tmux theme definitions (`dark.tmux` and `light.tmux`).
