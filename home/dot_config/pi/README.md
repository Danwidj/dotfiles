# Pi Coding Agent Configuration (`dot_config/pi/`)

Houses global configuration for [Pi Coding Agent](https://github.com/earendil-works/pi-coding-agent).

### Files

- **`agent/symlink_AGENTS.md.tmpl`**: Maps to `~/.config/pi/agent/AGENTS.md` (via `$PI_CODING_AGENT_DIR`). Symlinks to `~/.config/agents/AGENTS.md` for shared instructions.
