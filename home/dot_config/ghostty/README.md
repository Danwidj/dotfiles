# Ghostty Configuration (`dot_config/ghostty/`)

Houses settings for [Ghostty](https://ghostty.org/), a fast, native GPU-accelerated terminal emulator.

### Files

- **`private_config.ghostty`**: Maps to `~/.config/ghostty/config.ghostty`. Configures fonts (JetBrains Mono / Nerd Fonts), window padding, tab behavior, mouse bindings, and terminal appearance.
